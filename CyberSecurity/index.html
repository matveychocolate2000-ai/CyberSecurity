Архитектура сетевой защиты

Подробный разбор концепций сетевого взаимодействия, атак на веб-приложения, разграничения прав в Linux и принципов приватности.

1. Передача данных: Как клиент общается с БД

Любое действие в сети — это обмен сетевыми пакетами. Рассмотрим архитектуру трехзвенного приложения.

Клиент (Client)

Браузер / Приложение

Пользователь вводит данные (логин/пароль) или запрашивает страницу. Браузер формирует HTTP/HTTPS-запрос и отправляет его по IP-адресу сервера.

  • Шифрование TLS/SSL
  • Защита Cookie & Tokens
➡️
Сервер (Backend)

Веб-сервер / API

Сервер (Nginx, Node.js, Python, PHP) принимает запрос, проверяет авторизацию, валидирует входящие данные и решает, какой запрос отправить в базу.

  • Валидация входящих строк
  • WAF (Web Application Firewall)
➡️
База Данных (DB)

Хранилище (DBMS)

База данных (PostgreSQL, MySQL) выполняет SQL-команду, находит нужные записи и возвращает результат назад серверу. Прямого доступа из интернета к БД быть не должно.

  • Изоляция в локальной сети
  • Параметризованные запросы

🔑 Почему опасна передача данных без шифрования (HTTP)?

При использовании незащищенного протокола HTTP все данные передаются в открытом виде. Злоумышленник в вашей Wi-Fi сети с помощью анализатора трафика (например, Wireshark) может перехватить пароли, сессионные куки и персональную информацию (атака Man-in-the-Middle).

2. SQL-инъекции (SQLi): Суть, Механика и Дефенс

SQL-инъекция — один из самых опасных и старых видов атак на веб-приложения, входящий в топ OWASP Top-10.

Как происходит атака?

Уязвимость возникает, когда сервер склеивает пользовательские данные с SQL-кодом напрямую, не проверяя их содержимое.

Если код авторизации выглядит так:

SELECT * FROM users WHERE user = '$user' AND pass = '$pass';

Хакер передает вместо пароля строку: ' OR '1'='1. В результате итоговый запрос к БД превращается в:

SELECT * FROM users WHERE user = 'admin' AND pass = '' OR '1'='1';

Так как условие '1'='1' истинно всегда, база данных игнорирует проверку пароля и выдает доступ к аккаунту администратора.

Как защититься от SQLi?

1. Подготовленные выражения (Prepared Statements)

Использование параметризованных запросов разделяет код и данные. База сначала компилирует структуру SQL-запроса, а затем вставляет текст как безобидную строку.

2. Использование ORM

Фреймворки (SQLAlchemy, Prisma, Django ORM) автоматически экранируют и подготавливают все данные "из коробки".

3. Принцип наименьших привилегий

Пользователь базы данных, под которым работает веб-сайт, не должен иметь прав администратора БД (DROP TABLE, GRANT ALL).

3. Linux — Фундамент безопасности

Более 90% серверов, облачных инфраструктур и систем защиты работают на базе ядра Linux.

🐧

Дистрибутивы

Debian / Ubuntu / Rocky Linux — стандарты для боевых серверов благодаря стабильности.
Kali Linux / Parrot OS — специализированные системы с предустановленным инструментарием (Nmap, Metasploit, Burp Suite) для проведения аудита безопасности.

🔒

Права и Доступ (POSIX)

В Linux всё есть файл. Система строго контролирует права через владельца и группы:

  • chmod 600 file — чтение/запись только владельцу.
  • chown root:root — смена владельца на суперпользователя.

Запуск сервисов от имени обычных пользователей защищает систему при взломе приложения.

📦

Изоляция и Песочницы

Для предотвращения полного захвата сервера при взломе применяются технологии изоляции:

  • Docker / Containers: Сервер изолирован в собственном пространстве имен.
  • SELinux / AppArmor: Запрещают процессу выходить за рамки отведенных ему директорий.

4. Приватность: Зачем и как защищаться

Анонимность — это не про скрытие нелегальных действий, а про защиту от слежки, утечек и фингерпринтинга.

Инструмент Шифрование Скрытие IP От чего защищает Ограничения
HTTPS Сквозное (TLS) ❌ Нет Перехват содержимого запросов в открытом Wi-Fi. Провайдер видит, к какому домену вы обратились.
VPN Туннельное (AES-256) ✅ Да Слежка провайдера, региональные блокировки. Необходимость доверия серверу VPN.
Tor Network Многослойное (3 узла) ✅ Высокое Таргетированная слежка, цензура, анализ трафика. Низкая скорость, блокировка выходных узлов сервисами.

⚠️ Что такое Browser Fingerprinting (Отпечаток браузера)?

Даже при смене IP-адреса сайты могут идентифицировать вас по уникальному отпечатку: разрешению экрана, списку установленных шрифтов, видеокарте (Canvas API) и расширениям. Для защиты от этого используют специальные браузеры (LibreWolf, Mullvad Browser, Tor Browser).

5. Специалисты и Роли в Кибербезопасности

Кто защищает цифровой мир и чем отличаются подходы разных команд.

Blue Team / Защитники

Кто они: Системные администраторы, инженеры ИБ, специалисты SOC (Security Operations Center).

Задачи: Настройка файрволов (iptables/ufw), мониторинг логов, закрытие уязвимостей, настройка бэкапов и реагирование на инциденты.

Red Team / Белые хакеры

Кто они: Пентестеры (Тестировщики на проникновение), исследователи безопасности.

Задачи: Легальный взлом инфраструктуры по согласованию с владельцами. Находят бреши в коде и конфигурациях раньше, чем их найдут преступники.

Black Hat / Преступники

Кто они: Черные хакеры, киберпреступные группировки.

Задачи: Взлом систем ради финансовой выгоды, шантажа, шифрования данных вирусами-вымогателями (Ransomware) и кражи интеллектуальной собственности.
